# 요구사항 정의서 — 파일 확장자 차단 정책 관리

동작(behavior)과 제약조건(constraint)만 다룹니다. "왜 이런 정책이 필요한가"에
대한 판단 근거는 [`CONSIDERATIONS.md`](./docs/CONSIDERATIONS.md)를 참고해 주세요.

---

## A. 확장자 차단 정책 관리 화면

### A-1. 고정 확장자

**대상**
```
bat, cmd, com, cpl, exe, scr, js  (총 7개)
```

**기본 상태**
```
전부 unchecked
```

**동작 규칙**

- [x] 화면 진입 시, 각 확장자의 현재 차단 여부(checked/unchecked)를 조회하여 표시한다
- [x] 체크박스를 check/uncheck 하면 즉시 반영되어야 한다
- [x] 변경된 상태는 유지되어야 한다 → 새로고침 후에도 동일한 체크 상태가 보여야 한다
- [x] 7개 항목 외의 항목은 추가/삭제할 수 없다 (목록 자체는 고정)
- [x] 고정 확장자는 커스텀 확장자 목록 영역에 표시되지 않는다
- [x] 고정 확장자와 동일한 값을 커스텀 확장자로 등록 시도하면 **등록이 거부**되어야 한다

---

### A-2. 커스텀 확장자

**입력 제약**

| 항목 | 제약 |
|---|---|
| 최대 길이 | 20자 |
| 최대 등록 개수 | 200개 |

**동작 규칙 — 추가**

- [x] "추가" 클릭 시 입력값을 등록하고, 목록 영역에 즉시 표시되어야 한다
- [x] 등록된 항목은 새로고침 후에도 유지되어야 한다
- [x] 다음 경우 등록이 **거부**되어야 하며, 각각 사유가 사용자에게 전달되어야 한다
  ```
  ├─ 입력값이 20자를 초과하는 경우
  ├─ 이미 등록된 커스텀 확장자와 동일한 경우 (중복)
  ├─ 고정 확장자 목록에 이미 존재하는 값인 경우
  └─ 현재 등록 개수가 200개에 도달한 경우
  ```
- [x] 현재 등록 개수와 최대 개수를 화면에 표시한다 (예: `3/200`)

**동작 규칙 — 삭제**

- [x] 각 항목 옆 `X` 클릭 시 해당 항목이 삭제되어야 한다
- [x] 삭제 결과는 새로고침 후에도 유지되어야 한다 (재조회 시 삭제된 항목이 다시 나타나지 않아야 한다)

## B. 실제 파일 업로드 처리

**전제조건**
```
A에서 설정한 정책(고정 확장자 체크 상태 + 커스텀 확장자 목록)이
실제 파일 업로드 시점에 동일하게 적용되어야 한다.
```

**동작 규칙**

- [x] 업로드 요청된 파일의 확장자가 현재 차단 정책(A의 결과)에 해당하면, 업로드를 거부해야 한다
- [x] 거부 시 사용자에게 **무엇이 / 왜** 차단되었는지 명확한 사유가 전달되어야 한다
- [x] 차단 정책에 해당하지 않는 파일은 정상적으로 업로드 성공 처리되어야 한다
- [x] A 화면에서의 정책 변경 → B 업로드 동작에 **즉시** 반영되어야 한다 (재배포/재시작 없이)

## 범위 밖(Out of Scope)이었으나 구현된 항목 (스스로 발견/확장)

요구사항 문서상 명시되지 않았으나, 개발 과정에서 필요성을 발견해 추가 구현한
기능입니다. 판단 근거는 `CONSIDERATIONS.md`를 참고해 주세요.

```
- 매직바이트(파일 시그니처) 검증 — 확장자 위장 파일 대응 (CONSIDERATIONS.md 1-1)
- 정책 변경 이력(감사 로그) 저장 및 조회 (2-2)
- 더미 로그인 및 세션 기반 "누가 변경했는지" 추적 (2-2)
- 업로드 이력 조회 및 재다운로드 (본인 것만, 인증 기반) (2-5, 1-7)
- 동시성 방어 (200개 제한 TOCTOU 이슈 대응) (2-3)
```

---

## 범위 밖으로 두고 구현하지 않은 항목

```
- 파일 내용 기반 검증 중 종합 판별(모든 포맷 매직바이트 DB, Apache Tika 등)
- 이미지/PDF 메타데이터(EXIF) stripping
- SVG 내부 스크립트 sanitize
- 정책의 화이트리스트 방식 전환
- 사용자/조직별 정책 분리
- 실시간 동기화(웹소켓)
```
각 항목의 제외 근거는 `CONSIDERATIONS.md`에 상세히 기술되어 있습니다.
